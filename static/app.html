Local-First Skills Hub for Coding Agents & Creators

Install AgentBroko once to discover and execute creative skills from a single CLI. Automate video editing, offline speech synthesis, and developer handbook creation without cloud accounts, telemetry, or API keys.

npm install -g agentbroko

1. Installation & Setup

Select your preferred package manager or runtime to get started:

# Run instantly without installing anything
npx agentbroko skills

# Initialize a new video scaffold
npx agentbroko video-forge init my-video
# Install globally on your system
npm install -g agentbroko

# Run from anywhere in your terminal
agentbroko skills
# Run directly with pnpm dlx
pnpm dlx agentbroko skills

# Or install globally
pnpm add -g agentbroko
# Run directly with yarn dlx
yarn dlx agentbroko skills

# Or install globally
yarn global add agentbroko
# Clone and install locally in editable mode
git clone https://github.com/sajidhossain8272/agentbroko.git
cd agentbroko
pip install -e .

# Run via python module
python -m agentbroko skills
Prerequisites: Python 3.10+ and ffmpeg / ffprobe on your PATH for video rendering.

2. Skill: Video Forge (Video Editing)

Video Forge is a local-first video editing skill for humans and coding agents. Initialize video projects, generate offline TTS speech, create synchronized SRT subtitles, and render MP4 videos: 

# 1. Check local tools (FFmpeg, FFprobe, TTS engines)
agentbroko video-forge doctor

# 2. Create a new video project scaffold
agentbroko video-forge init my-video

# 3. Validate project schema without rendering
agentbroko video-forge validate my-video/project.json

# 4. Generate speech narration from a text script (offline TTS)
agentbroko video-forge speak --file my-video/script.txt --output my-video/audio/narration.wav

# 5. Create synchronized SRT captions
agentbroko video-forge captions --file my-video/script.txt --output my-video/captions/subtitles.srt

# 6. Render the final MP4 video
agentbroko video-forge render my-video/project.json

3. Skill: PDF Playbook

Generate polished, dark-theme 20-page developer handbooks with structured tables, chapters, checklists, and code layouts using ReportLab: 

# Interactive wizard mode (prompts for title, audience, and core promise)
agentbroko pdf-playbook --output my-guide.pdf
# Non-interactive automated build for scripts and headless agents
agentbroko pdf-playbook --non-interactive --output production-playbook.pdf

4. Skill: Local PDF Utilities

Extract text, inspect metadata, and render PDF pages completely offline without sending documents to third-party APIs: 

# Inspect PDF metadata & page count
agentbroko pdf info document.pdf
# Extract clean UTF-8 text from PDF
agentbroko pdf text document.pdf --output document.txt
# Render PDF pages to high-resolution PNG images (requires Poppler)
agentbroko pdf render document.pdf --output rendered-pages/
