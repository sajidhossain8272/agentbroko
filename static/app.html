1. Installation & Quick Start

Run AgentBroko via npm (Node.js 18+) or install directly with Python 3.10+:

# Run instantly with npx (no global install needed)
npx agentbroko skills

# Or install globally with npm
npm install -g agentbroko
agentbroko skills

# Or install with Python pip
git clone https://github.com/sajidhossain8272/agentbroko.git
cd agentbroko
pip install -e .
🎬

2. Skill: Video Forge (Video Editing)

Create vertical shorts or landscape ads, generate narration from text, extract subtitles, and render complete MP4 videos with FFmpeg:

# Check local tools (FFmpeg, FFprobe, TTS engines)
agentbroko video-forge doctor

# Initialize a new video project scaffold
agentbroko video-forge init my-video

# Validate project.json specification
agentbroko video-forge validate my-video/project.json

# Generate speech narration from a text script
agentbroko video-forge speak --file my-video/script.txt --output my-video/audio/narration.wav

# Generate synchronized SRT captions
agentbroko video-forge captions --file my-video/script.txt --output my-video/captions/subtitles.srt

# Render the final MP4 video
agentbroko video-forge render my-video/project.json
📄

3. Skill: PDF Playbook

Generate polished, dark-theme 20-page developer handbooks with structured tables and sections using ReportLab:

# Generate a developer playbook interactively
agentbroko pdf-playbook --output my-guide.pdf

# Non-interactive automated build
agentbroko pdf-playbook --non-interactive --output production-playbook.pdf
📑

4. Skill: Local PDF Utilities

Extract text, inspect metadata, and render PDF pages completely offline without sending documents to third-party APIs:

# Inspect metadata & page count
agentbroko pdf info document.pdf

# Extract clean text from PDF
agentbroko pdf text document.pdf --output extracted.txt

# Render PDF pages to images (requires Poppler)
agentbroko pdf render document.pdf --output rendered-pages/
