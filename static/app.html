Local-First Skills Hub for Coding Agents & Creators

Install AgentBroko once to discover and use skills from a single CLI. Automate video editing, offline speech synthesis, and developer handbook creation without cloud accounts, telemetry, or API keys.

npm install -g agentbroko

1. Installation & Setup

AgentBroko is available as a global npm launcher or directly as a Python 3.10+ package:

bash / zsh / powershell
# 1. Run instantly with npx (no global install needed) npx agentbroko skills # 2. Or install globally with npm npm install -g agentbroko agentbroko skills # 3. Or install via Python pip git clone https://github.com/sajidhossain8272/agentbroko.git cd agentbroko pip install -e .
Prerequisites: Python 3.10+ and ffmpeg / ffprobe on your PATH for video rendering.

2. Skill: Video Forge (Video Editing)

Video Forge is a local-first video editing skill for humans and coding agents. Initialize video projects, generate offline TTS speech, create synchronized SRT subtitles, and render MP4 videos:

video-forge commands
# Check local tools (FFmpeg, FFprobe, TTS engines) agentbroko video-forge doctor # Create a new video project scaffold agentbroko video-forge init my-video # Validate project schema without rendering agentbroko video-forge validate my-video/project.json # Generate speech narration from a text script (offline TTS) agentbroko video-forge speak --file my-video/script.txt --output my-video/audio/narration.wav # Create synchronized SRT captions agentbroko video-forge captions --file my-video/script.txt --output my-video/captions/subtitles.srt # Render the final MP4 video agentbroko video-forge render my-video/project.json
project.json specification
{ "output": "outputs/final.mp4", "title": "My Video", "video": { "width": 1920, "height": 1080, "fps": 30 }, "clips": [ { "source": "media/clip-01.mp4", "start": 0, "duration": 5, "speed": 1, "volume": 1 } ], "audio": { "narration": "audio/narration.wav", "music": null, "music_volume": 0.12 }, "subtitles": "captions/subtitles.srt" }

3. Skill: PDF Playbook

Generate polished, dark-theme 20-page developer handbooks with structured tables, chapters, checklists, and code layouts using ReportLab:

pdf-playbook commands
# Interactive wizard (prompts for guide title, audience, and core promise) agentbroko pdf-playbook --output my-guide.pdf # Non-interactive automated build for scripts and CI/CD agentbroko pdf-playbook --non-interactive --output production-playbook.pdf

4. Skill: Local PDF Utilities

Extract text, inspect metadata, and render PDF pages completely offline without sending documents to third-party APIs:

pdf utilities
# Inspect PDF metadata & page count agentbroko pdf info document.pdf # Extract clean text from PDF (requires pypdf) agentbroko pdf text document.pdf --output document.txt # Render PDF pages to images (requires Poppler) agentbroko pdf render document.pdf --output rendered-pages/
