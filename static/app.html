                        ⚡ AgentBroko Skills Terminal & NPM Hub
                    

                    Zero API Key Required
                


                

                    AgentBroko is distributed as both a web studio and a self-contained NPM/Python package. Run skills from your terminal or integrate them into your coding agents with zero cloud dependencies.
                


                

                    

                        

                            
npx agentbroko skills

                            
List all available skills (Video Forge, PDF Playbook, PDF Tools)

                        

                        
                    


                    

                        

                            
npx agentbroko video-forge init my-video --vertical

                            
Initialize a new 9:16 vertical Video Forge project scaffold

                        

                        
                    


                    

                        

                            
npx agentbroko video-forge render my-video/project.json

                            
Render the complete video with voiceover, audio bed, and kinetic captions

                        

                        
                    


                    

                        

                            
npx agentbroko pdf-playbook --output playbook.pdf

                            
Generate a complete 20-page developer handbook using ReportLab

                        

                        
                    


                    

                        

                            
npx agentbroko pdf text document.pdf --output document.txt

                            
Extract text from local PDFs offline with zero cloud upload
