# Roadmap

## Current

- Stable AgentBroko skill discovery and Video Forge routing.
- Local JSON-based video rendering, captions, mixing, and offline narration.

## Planned

- Plugin-style skill discovery without editing the core router.
- Improved transitions, audio-only inputs, and silent-video support.
- Better progress reporting and render diagnostics.
- Package release automation with trusted publishing.
- Additional local-first creative and developer skills.

Roadmap items are proposals, not guarantees. Discuss substantial additions in an issue before implementation.
