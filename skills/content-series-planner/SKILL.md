# Content Series Planner

Use when the user wants a multi-part video series.

Return a series promise, audience, format, episode table, season arc, recurring intro/outro, visual and audio identity, production checklist, release cadence, and metadata strategy. Give every episode a distinct hook and lesson while maintaining continuity. Track source status for factual, religious, and historical topics. Mark unresolved research, dramatization, and fiction clearly.

Design episodes to flow into the existing Video Forge `universal_story` template and keep each episode independently understandable.
