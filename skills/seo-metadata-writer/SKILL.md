# SEO Metadata Writer

Use when the user wants publishing metadata for a video.

Collect the verified topic, platform, audience, series/episode number, source links, and call to action. Return platform-specific title options, a description, chapters/timestamps, tags, hashtags, disclosure text, and an optional pinned comment. Match the primary keyword across title and opening description naturally. Avoid keyword stuffing, fake authority, guaranteed performance claims, misleading hooks, and invented citations.

For religious, historical, or documentary content, include a source note and distinguish sourced fact, interpretation, dramatization, and fiction.
