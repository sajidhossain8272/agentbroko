# Thumbnail Generator

Use when the user needs a thumbnail, cover frame, or social preview for a video.

1. Ask for platform, aspect ratio, title, audience, subject image, and brand kit.
2. Choose one focal subject, one short curiosity hook, strong contrast, and a clear safe area.
3. Never fabricate a person, quote, source, or event. Mark dramatized or generated imagery when relevant.
4. Produce a design brief with dimensions, background, focal point, typography, colors, text placement, and export format.
5. When local image tooling is available, create the image and verify its dimensions; otherwise provide the complete production prompt and layout specification.

For vertical shorts, default to 1080x1920 and keep important text away from platform UI zones.
