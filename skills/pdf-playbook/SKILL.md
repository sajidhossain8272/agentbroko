# PDF Playbook

Use when the user wants a handbook, playbook, guide, or multi-page technical PDF.

1. Clarify title, audience, topic, tone, and desired length.
2. Create a structured specification with chapters, leads, items, examples, and checklists.
3. Keep claims sourced or label them as recommendations.
4. Compile with `npx agentbroko pdf-playbook --spec playbook_spec.json --output playbook.pdf` when local execution is available.
5. Report the exact output path and inspect the PDF before delivery.

Do not claim a PDF was rendered when only the specification was produced.
